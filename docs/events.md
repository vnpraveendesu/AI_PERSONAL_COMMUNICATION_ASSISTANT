# Application Events

## Email Events

| Event | Description |
|---|---|
| email.received | New email discovered |
| email.updated | Existing email changed |
| email.deleted | Email deleted |
| email.sync.completed | Account synchronization completed |

## AI Events

| Event | Description |
|---|---|
| ai.job.created | AI processing request created |
| ai.processing.started | LLM processing started |
| ai.processing.completed | Summary generated |

## Leave Events

| Event | Description |
|---|---|
| leave.detected | Leave information extracted |
| leave.confirmed | User confirmed leave |
| leave.report.generated | Leave report created |
